# סיור דיגיטלי – 4 חדרים

סיור 360° בדירת 4 חדרים, מבוסס על רינדורים פוטוריאליסטיים מ-Blender (Cycles).

- `index.html` – דף הסיור
- `pano.js` – נגן ה-360° (three.js)
- `tour_data.js` – נקודות הסיור והמעברים בין החדרים
- `pano_*.js` – תמונות הפנורמה של כל נקודה

לצפייה: מפעילים GitHub Pages על הענף `main` (תיקיית root), והסיור יעלה בכתובת
`https://<שם-המשתמש>.github.io/housetour/`
